四个方向差别在气质，不在骨架。骨架是四个都统一改掉的东西：顶栏压成一行（现在手机端顶部三层固定区吃掉 23% 屏幕）、去掉和首页重复的"活动"tab、卡片只留封面 / 时间 / 标题 / 地点 + 谁在去（现在一张卡 10 层信息）、主按钮固定在底部（现在详情页要滑到第 3.3 屏才看到"申请"）、删掉全部免责文案、换上真正的中文字体（现在是 Arial 回退）。 内容说明：创始团队饭局和两个内测局是站上真实活动；C 方向里标了"示例"的卡片只是为了看双列排版效果。
对标 DICE / Luma 暗色

A · 夜色版

动机：保留你现在的暗色基调和品牌红，但做成夜生活产品该有的样子：纯黑底、边到边大海报、一个高饱和珊瑚红、粗标题字（ZCOOL 青柯黄油体）。和现有站点迁移成本最低，改 CSS 和布局就能到。

代价：暗色对"女生友好 / 安全"的信任感帮助不大，饭局、桌游这类白天场景略显不搭。

对标 Luma

B · 日光版

动机：米白底 + 宋体标题 + 一个梅子色，最像 Luma 的信息层级：缩略图在左、时间标题地点在右、按日期分组。最适合"女生友好、安全、可信"的定位，也是四个里最容易做好看、最不容易做丑的。

代价：和"今晚 / 夜生活"的品牌名气质有距离，蹦迪、KTV 场景会显得太乖。

对标 小红书

C · 海报墙

动机：留学生已经养成的浏览习惯：双列图片流、标题两行、Host 头像 + 想去数、顶部横向分类 tab。内容密度最高，供给多了以后最有"热闹"感，也最适合把 Eventbrite / 学联 / 小红书上搬来的活动混在一起展示。

代价：只有 3 个活动时会很空；对封面图质量要求最高，Host 不会拍照的话整页会很丑。

对标 Partiful

D · 搭子版

动机：把"报名"变成"回复群消息"：来 / 可能 / 不来 三个按钮，"谁来了"放最前面，Host 的介绍做成聊天气泡，贴纸式标签、粗描边、纯色块不依赖照片。最有记忆点，最适合小局和微信群里口碑传播。

代价：风格最重，做不好会显得幼稚；对聚合第三方活动不友好，因为它假设每个局背后都有一个真人 Host。
